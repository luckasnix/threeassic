# Threeassic

![Threeassic logo featuring a low-poly Tyrannosaurus rex above the wordmark.](./assets/logo.webp "Threeassic logo")

A TypeScript starter for 3D game development using Deno, Vite, and Three.js. Compile to web or desktop.

## 🛠️ Built with

- [TypeScript](https://www.typescriptlang.org) keeps game code typed and maintainable.
- [Deno](https://deno.com) provides the runtime, dependency management, and development tasks.
- [Vite](https://vite.dev) runs the web development server and production build.
- [Three.js](https://threejs.org) provides the 3D rendering foundation.
- [Three.js Gamepad Controls](https://github.com/luckasnix/three-gamepad-controls#readme) provides general-purpose gamepad input and integrations for Three.js controls.
- [Rapier](https://rapier.rs) supplies high-performance 3D physics.

## 🚀 Getting started

Install [Deno](https://docs.deno.com/runtime/getting_started/installation/), then run the following commands from the project root:

```bash
# Start the web development server
deno task dev

# Create a production web build
deno task build

# Preview the production web build locally
deno task preview

# Run the desktop application
deno task desktop
```
